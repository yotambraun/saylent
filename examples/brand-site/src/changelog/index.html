Changelog

Newest first. Anything that changes how alerting behaves is announced here before it ships.

2026-08-19

São Paulo region

Checks now run from a fourth region, gru-1. Existing checks picked it up automatically and the agreement rule counts it like any other region. Response time charts show the four regions separately.

2026-07-30

Observation mode for new checks

A new check watches for its first hour without paging anyone, so a typo in an expectation rule cannot wake the on call engineer. You can end observation early from the check page.

2026-07-02

Deploy markers on incidents

Deploys recorded through the API are now attached to any incident that opens within 30 minutes, and they appear on every response time chart.

2026-06-11

Private status pages

Squadron plans can publish a status page that needs a token link and is not indexed, for customers who should not see the public page.

2026-05-28

Heartbeat checks

Cron jobs and workers can call a Kestrel URL when they finish. An incident opens when the call does not arrive inside the window you set.
